8. Debugging and observability; no sensitive logs.

## Practical capstone: Silveroak AI Software Factory V1
Input a non-sensitive project specification. Produce a requirements sheet, technical plan, isolated work branch, tests, documentation, PR draft and deployment checklist. Nothing runs autonomous production writes by default.

### Proposed agents
- Project Architect — produces architecture drafts.
- Code Assistant — proposes source code in isolated branches.
- Testing Agent — proposes tests and error findings.
- Debugging Agent — suggests fixes with evidence.
- Documentation Agent — writes user and developer guidance.
- Security Review Agent — flags risks; not a guarantee of safety.
- Release Coordinator — prepares approvals and rollout notes.
All agents share the existing orchestrator, identity, audit and human approval services.

## Acceptance criteria
- Training materials are original, not copied from proprietary live course resources.
- Learners can configure a repository, run unit tests, and open a reviewed PR.
- Build, lint and tests pass before a release is considered deployable.
- Secrets remain in approved secret storage; no live customer data in exercises.
- Cost controls and human approval are required for deployment, purchases, external messaging and repository merges.
- Project and curriculum status displayed as **planned** until separately implemented and tested.
