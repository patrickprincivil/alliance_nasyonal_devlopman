# Silveroak App Factory — client delivery checklist

## Lead and quoting
- Collect business name, consent and high-level requirements; avoid requesting sensitive identity documents.
- Confirm contact details and schedule discovery.
- Identify business outcomes, target users, content ownership, language and accessibility requirements.
- State package inclusions/exclusions and propose milestone-based pricing in CAD.
- Quote domain, hosting, messaging, AI API and payment-processing costs separately.
- Obtain client approval of scope and deposit through a verified payment provider.

## Build
- Use approved reusable template and unique client branding/assets.
- Track client project in restricted workspace, not public demo files.
- Build accessible, mobile-first pages; validate forms on the server in production.
- Make clear AI responses can be wrong; add escalation to a person.
- Use environment secrets, limited data retention, MFA for administrator accounts.
- Store minimum necessary data; use customer-specific access controls.

## Test, approval and delivery
- Run lint, build, functionality, mobile, performance and accessibility checks.
- Validate privacy/terms pages and cookie/analytics consent where required.
- Client approves preview before launch.
- Deployment requires human authorization and CI success.
- Handoff domain/DNS, backups, account ownership, operating manual and support channels.
- Define maintenance, renewal, cancellations and deletion/export policy.

## Current status
A basic email-draft intake page and package landing page are only a prototype.
No server-side CRM, payment processor, client login, autonomous agent or production deployment has been configured.
