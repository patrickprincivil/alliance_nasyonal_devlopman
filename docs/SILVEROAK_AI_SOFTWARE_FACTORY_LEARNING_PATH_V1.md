# Silveroak AI Software Factory — practical learning pathway

Existing Global Academy specification stays canonical at docs/SILVEROAK_GLOBAL_ACADEMY_V2.md. This document adds the practical Python/AI curriculum without replacing it.

## Eight learning units
1. Python and virtual environments: CLI, packaging, typing.
2. Git, GitHub branches and reviewable pull requests.
3. Requirements, architecture and structured prompts for AI-assisted coding.
4. Automated tests, debugging, pytest and failure analysis.
5. Safe reusable instructions and human-supervised agent workflows.
6. Terminal dashboards and tools (Click/Textual examples).
7. Security reviews, secrets handling, permissions and prompt injection.
8. CI, deployment previews, human approval and rollback plans.

## Capstone
Build a local task tracker with Python CLI and tests. Add lint and a draft PR. Never auto-merge, charge, message third parties or deploy without approval.

## Third-party source policy
Real Python Claude Code workshop is a separate third-party offering. Verify current dates, tuition, instructor and subscription requirements on its official website. Do not copy its teaching materials or imply partnership with it.

## Exit gates
- Learner can run tests and explain failures.
- Instructor reviews security and reproducibility.
- Human reviewer approves any external publishing or production change.
- Courses are proposed: this commit does not implement online delivery or credentials.
